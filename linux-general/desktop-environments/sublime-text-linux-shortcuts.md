# Must-know keyboard shortcuts for Sublime Text on Linux

## Navigation and File Management

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + P` | **Goto Anything:** Quickly open files by name. |
| `Ctrl + R` | **Goto Symbol:** Jump to a specific function or class within the current file. |
| `Ctrl + G` | **Goto Line:** Jump directly to a line number. |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | Cycle through open tabs (recent order). |
| `Alt + [1-9]` | Switch to a specific tab by its numerical position. |

## Multi-Cursor and Selection

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + Click` | Add a new cursor at the clicked location. |
| `Ctrl + D` | Select the next occurrence of the current word. |
| `Alt + F3` | Select *all* occurrences of the current word in the file. |
| `Ctrl + Shift + L` | Split a multi-line selection into individual cursors on each line. |
| `Shift + Right Click` (Drag) | Column/Block selection. |

## Editing and Manipulation

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + Shift + D` | Duplicate the current line (or selection). |
| `Ctrl + Shift + Up/Down` | Move the current line (or selection) up or down. |
| `Ctrl + /` | Toggle comment for the current line or selection. |
| `Ctrl + Shift + /` | Toggle block comment. |
| `Ctrl + J` | Join the line below to the end of the current line. |

## Command Palette and Configuration

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + Shift + P` | Open the **Command Palette** (Access Package Control, syntax changes, etc.). |
| `Ctrl + \`` | Toggle the internal Python console. |
| `F11` | Toggle Full Screen mode. |
| `Shift + F11` | Toggle Distraction Free mode. |
